# Мои задачи

PWA-приложение на русском языке для iPhone и MacBook.

## Возможности
- Добавление, изменение, удаление и отметка выполнения задач
- Описание/заметки, проекты, приоритеты, сроки и статусы
- Фильтры: все, сегодня, предстоящие, просроченные, выполненные
- Поиск, сортировка, ближайшие сроки и обзорная статистика
- Экспорт списка задач в CSV
- Автономная работа и локальное хранение
- Необязательная синхронизация между устройствами через Supabase Auth + Postgres + RLS

## Важно о синхронизации
Синхронизация заработает после создания собственного проекта Supabase и ввода URL/ключа в приложении. Пока это не сделано, данные остаются локальными в браузере текущего устройства. Установка приложения на два устройства сама по себе синхронизацию не включает.

## Подключение облака
1. Создайте проект на https://supabase.com/.
2. Откройте SQL Editor в проекте, вставьте весь файл `supabase-schema.sql` и выполните.
3. В настройках API проекта скопируйте Project URL и publishable key (или legacy anon key). **Не используйте service_role/secret key в клиентском приложении.**
4. Разместите приложение на HTTPS-хостинге (например, GitHub Pages).
5. На первом устройстве откройте «Синхронизация», вставьте URL и ключ, нажмите «Сохранить настройки», затем «Создать аккаунт» или «Войти».
6. На втором устройстве откройте ту же опубликованную страницу, введите тот же URL и ключ и войдите в тот же аккаунт.

Если включено подтверждение email в Supabase Auth, подтвердите адрес из письма перед входом. Для простого личного использования храните URL и publishable/anon key; пароль аккаунта никому не сообщайте.

## Установка на iPhone
1. Разместите файлы на HTTPS-хостинге.
2. Откройте адрес в Safari.
3. Нажмите «Поделиться» → «На экран Домой» → «Добавить».

## Установка на MacBook
Откройте опубликованный HTTPS-адрес в Safari или другом современном браузере. Для удобного запуска можно добавить сайт в Dock/закладки; способ установки как приложения зависит от версии браузера и macOS.

## Ограничения текущей версии
- Это веб-приложение (PWA), не нативное приложение из App Store.
- Проекты хранятся в локальной настройке устройства, а задачи синхронизируются через Supabase. Для полностью одинакового списка проектов на разных устройствах потребуется отдельная таблица проектов — пока категории проекта синхронизируются как текст/ID задачи.
- Если изменять одну и ту же задачу одновременно на двух устройствах, автоматическое разрешение конфликтов ограничено; перед важными изменениями дождитесь завершения синхронизации.
- Для защиты данных применяются Supabase Auth и политики RLS. Используйте только publishable/anon key в браузере, никогда не публикуйте service_role/secret key.
