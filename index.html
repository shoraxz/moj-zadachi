НАСТРОЙКА

Синхронизация

⇄
Подключите облако

Один и тот же список задач на iPhone и MacBook. Для этого понадобится бесплатный проект Supabase.

Сейчас данные сохраняются только в браузере на этом устройстве. Чтобы включить синхронизацию, создайте проект Supabase и заполните поля ниже.

Используйте только publishable/anon ключ. Никогда не вставляйте service_role или secret key в приложение.

Как подключить облако?
  1. Откройте supabase.com и создайте проект.
  2. В проекте откройте SQL Editor, вставьте весь код из файла supabase-schema.sql из архива приложения и нажмите Run.
  3. В настройках API проекта скопируйте Project URL и publishable key (или anon key) в поля выше.
  4. Создайте аккаунт с электронной почтой и паролем. При включённом подтверждении почты сначала подтвердите адрес.
  5. Повторите вход на втором устройстве с теми же настройками и аккаунтом.
